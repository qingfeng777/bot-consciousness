# 多模态输入与知觉

> 实现路线更新（0.5.0）：本模块需要的模型生成统一经云端 API 与版本化提示词，使用 [云端模型方案](../cloud-models.md) 中对应 purpose；本地只保留适配、状态、校验和验证流程。

模块编号 M02。将文本、图像、音频和采样视频转换为带证据的语义观察。负责观察结果，不负责判断哪个目标优先，也不把识别推测写成确定事实。

## 输入输出与组件

RawInput 含 input_id、device_id、modality、capture_interval、content_ref、checksum 和采集质量。SemanticObservation 含 observations、entities、modality、confidence、source_refs、capture_interval、revision 和 partial。每条观察保留对应图像区域、音频时间段或文本片段。

组件包括 TextNormalizer、AudioSegmenter、SpeechAdapter、ImageAdapter、VideoSampler、TemporalAligner 和 EvidenceAssembler。文本直入时仍做长度、编码、来源及重复检查；图片先做质量筛选；音频区分语音活动、转录和声学事件；视频先按固定间隔及变化检测采样，不把连续流逐帧交给语言模型。

## 核心流程

采集 → 质量检查 → 分段或采样 → 模态适配 → 证据绑定 → 输出初步观察 → 到达晚期证据时发新 revision。音频中途结果不能覆盖最终结果，最终结果通过 supersedes 指向旧版本。

跨模态融合仅在时间窗口、设备位置与实体候选兼容时进行。第一版先并列证据，只有一致的观测才合并；冲突交给 M18。低质量输入输出 unknown 或请求重采样，不能靠语言模型补全看不见的对象。

## 难点与实验

R02-1：中文噪声语音与紧急声学事件。使用不同距离、混响、噪声和说话者的分层样本，比较转录后规则与独立声学识别；指标分别记录漏报、误报及延迟。

R02-2：视觉实体跨帧关联。比较只描述帧与带轨迹 ID 的方案，评估实体切换率、关系正确率和证据定位。识别分数并非天然可比较的概率，校准按模态分别进行；校准不成立时输出等级和原始分数。

## 故障与验收

模型超时输出 perception_unavailable，不重复排队直至堆积。丢帧和缺音标记缺口；时钟偏移超阈值时关闭自动融合。原始媒体按可配置期限清理，证据已删除时保留“不可复查”标志。

验收包括纯文本、噪声语音、模糊图、暗光、空画面、同音词、重叠说话和视频断流。观察必须可回溯输入，模态失败不阻塞其他模态；定量阈值由标注集基线决定，关键紧急信号漏报单独作为准入项。

## 开发拆分

- M02-A：输入契约、分层样本及质量判定，建立单模态基线。
- M02-B：文本及图像音频适配、视频采样、证据绑定和限流。
- M02-C：跨模态对齐、置信度校准实验和噪声回归；融合失败时保留并列观察。
