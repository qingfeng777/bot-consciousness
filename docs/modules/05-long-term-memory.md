# 长期记忆与证据检索

模块编号 M05。持久保存经历、知识和证据，提供有时间范围的检索，不以向量相似度决定事实真伪。

## 记忆类型与表设计

区分 episodic 经历、semantic 事实、procedural 技能引用和 hypothesis 假设。MemoryRecord 保存主体、谓词、宾语或正文、valid_from、valid_to、recorded_at、source_ids、confidence、status、version；时间采用有效时间与记录时间双轴。

memories 为内容主表，evidence_edges 记录 supports、contradicts 和 derived_from，memory_versions 保存修订，retrieval_index_state 保存索引版本。技能可执行定义由 M16 管理，此处仅保存技能索引及引用。

## 写入与读取流程

观察 → 候选提取 → 来源和类型校验 → 精确去重 → 冲突检测 → 事务写入版本 → 异步更新检索索引。索引更新失败不回滚已确认事实，但标记索引落后并允许基于结构字段或全文检索回退。

检索先按机器人、实体、场景、时间和类型过滤，再合并关键词与语义候选，按相关性、证据质量和时间适用性重排，最后去重与预算裁剪。返回 RetrievalHit 含 memory_id、revision、证据、适用时间、排序分解和 conflict_group，不隐藏冲突项。

新写内容不能自动因为“更新”而比可信旧证据更可靠；遗忘优先移除可再生成索引、过期媒体和低价值缓存，事实删除需同时处理引用、摘要和向量索引，并记录墓碑。

## 难点与实验

R05：跨场景召回、时间过滤和相似错误事实的区分。建立有答案证据集合的查询集，并按人物、物体和时间切分训练与验收集合，防止同一事件改写后泄漏。

比较全文、结构过滤加全文、混合检索三个基线；记录 Recall@10、证据准确率、时间误用率、冲突遗漏率及 p95 延迟。向量化只在召回改善且无不可接受误检时加入，不预先绑定供应商。

## 异常与验收

处理重复导入、索引重建中查询、引用删除和恢复旧数据库。检索接口必须显式返回 stale_index 或 evidence_missing。验收要求所有生效事实有来源，冲突未解决时返回不确定状态；备份恢复后同一查询的结构过滤结果一致。

## 开发拆分

- M05-A：记忆本体、时间语义、标注查询及检索基线。
- M05-B：事务写入、版本、证据边、索引及过滤检索。
- M05-C：混合检索评估、删除传播、备份和索引重建验证。
