# 场景记忆与实体关系

模块编号 M06。将离散观察组织为可查询的场景和事件序列，为目标与记忆提供空间、时间和角色上下文。

## 数据与职责

Scene 包含 scene_id、时间区间、地点引用、entity_tracks、relations、episodes、uncertainties 和 revision。EntityTrack 保存局部跟踪 ID、候选实体 ID、特征引用和匹配证据；不同来源的同名人物不能直接视为同一人。

内部组件为 BoundaryDetector、EntityResolver、RelationUpdater、EpisodeAssembler 和 SceneSummarizer。场景表示是带时间区间的实体关系图；长期人物属性交 M05，场景不直接修改稳定身份。

## 更新算法

按观测时间窗口接收事件 → 根据地点及主要实体变化判定场景边界 → 关联或创建实体轨迹 → 更新关系有效区间 → 聚合事件片段 → 输出场景差异。晚到观察在允许窗口内生成新 revision，窗口外记录历史修正，不直接改变当前动作假设。

实体关联按设备轨迹、时间连续性和可验证特征打分；分数接近时保留多候选，待补充证据再合并。合并和拆分均保留映射版本，检索能追溯以前使用的实体 ID。

场景摘要描述观察及不确定关系，例如“可能是同一杯子”，不能将“未观测到”推成“不存在”。场景结束时写入经历摘要及原始事件索引。

## 难点与实验

R06：场景切换、遮挡后重识别与实体关系稳定性。构建进出房间、人物同名、物体移动、摄像头断流和时间错位场景，评估边界准确率、实体错误合并率、关系时序准确率。

首版以显式地点和设备轨迹为基线；纯语义自动实体合并只在人工标注评估通过后启用。不确定匹配保留多个 ID 比不可逆误合并更易恢复。

## 异常与验收

位置不可用时标记 unknown；观察断流不自动终结所有实体。验收要求同一轨迹重放产生稳定版本、错误合并可拆回、历史检索不把过去关系当作现在状态。

## 开发拆分

- M06-A：场景边界、实体本体及关联评估集。
- M06-B：关系时间区间、实体映射版本和片段聚合。
- M06-C：遮挡、迁移和乱序场景回归与误合并修复工具。
