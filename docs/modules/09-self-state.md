# 自我状态与自我评估

模块编号 M09。形成可核验的设备与行为自我模型，包含“知道哪些状态”和“不知道哪些状态”，而非生成一段自我描述。

## 数据与组件

TelemetrySample 含 metric、value、unit、sensor_id、sample_time、quality 和 ttl。SelfSnapshot 含电量、温度、部件健康、可用能力、当前动作、最近失败及各字段有效性。字段状态为 known、degraded、unknown，不使用一个总体置信度掩盖关键传感器失效。

组件为 TelemetryAdapter、UnitNormalizer、HealthEstimator、CapabilityResolver 和 SelfEvaluator。设备事实来自遥测与驱动，行为状态来自执行记录，主观评价与情绪单独保存，不能反向覆盖传感器值。

## 更新和调节

校验单位及范围 → 对齐设备时间 → 过滤孤立异常或标记异常 → 计算窗口趋势 → 更新健康等级 → 产生 SelfStateChanged 与 NeedSignal。阈值与迟滞由设备配置给出，原始样本保留用于复查。

“电量低于 20% 生成需求、恢复至 30% 解除”仅为仿真配置。动作能量估计用实际完成的遥测差校准；无可靠估计时只给区间，避免承诺剩余续航。自我调节产生任务候选，例如降载、检查或充电，仍经调度执行。

## 难点与实验

R09：低质量遥测、能耗估计和部件异常识别。先用确定阈值及滑动趋势，再以标注故障比较预测模型；若预测缺乏提前量或误报过多，则保留阈值告警，不把研究失败阻塞主系统。

自我评估核对计划预期与实际结果，输出可测偏差；“我擅长某技能”需有适用环境下的成功率及样本数支撑。

## 验收与拆分

验收包括非法单位、NaN、设备时间漂移、电量抖动、遥测断流及自我描述与实测矛盾。关键状态过期后前置条件不再成立；恢复遥测后按迟滞规则解除限制。

- M09-A：遥测字典、有效期与健康规则。
- M09-B：时间与单位归一、状态快照、能力可用性及需求事件。
- M09-C：故障遥测回放和能量估计校准；无法校准的能力标记未知。
