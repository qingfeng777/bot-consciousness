# 程序性记忆与技能系统

模块编号 M16。把已验证行为步骤封装为可调用、可暂停、可核验的技能，而非仅保存命令列表。

## 技能表示

SkillDefinition 包含 skill_id、version、parameters、preconditions、step_graph、postconditions、resource_budget、applicable_context、checkpoints 和 compensation_policy。节点仅引用注册能力、受限条件判断或子技能；调用图无环或有明确迭代上限。

SkillRun 保存当前节点、变量、已确认效果、检查点、原计划版本和结果。技能定义不可变，升级生成新版本；运行实例锁定版本，不能执行一半自动换版。

## 编译与运行

定义校验 → 参数实例化 → 子技能展开并检查预算 → 生成调度器可管理步骤 → 每步重验前置条件 → 执行并核对后置条件 → 到达安全边界写检查点。技能不能自建执行线程绕过 M08。

暂停后恢复检查实际设备状态和已完成效果；若条件不再满足，返回重规划需求。补偿是新的受调度动作，例如已拿起物体后放回指定位置；不能声称补偿能撤销所有外部效果。

## 难点与实验

R16：适用条件是否充分，固定程序是否能适配环境变化。用同一技能在不同物体位置、缺失依赖和中断点下验证，统计成功率、恢复成功率与不必要重试。学习模块提出的技能先经过同一编译器及验收器。

首版技能仅支持顺序、条件分支和有界重试；并发行为树、连续控制策略和无界循环均后置，底层实时运动控制由设备控制器负责。

## 验收与拆分

检测循环依赖、未注册能力、参数越界、预算膨胀和不可恢复检查点。验收要求中断后不重复已确认动作，版本升级不影响在运行实例，技能失败能定位到步骤和证据。

- M16-A：技能 DSL、编译规则及检查点语义。
- M16-B：版本库、实例化、步骤执行和恢复接口。
- M16-C：环境扰动、嵌套技能预算和中断恢复验证。

研发工作包估算和依赖见 [模块工作包](../work-breakdown.md)，系统验收要求见 [跨模块协议与验证](../system-contracts.md)。
