# 模型交互格式校验与规划

模块编号 M13。将目标和证据转为结构化计划，并支持约束检查与重规划。模型是候选生成器，运行时决定候选是否能执行。

## 内部分层

ModelGateway 负责供应商适配、请求预算、流式收集、超时、取消与调用记录；ContextAdapter 接收 M04 不可变快照；PlanGenerator 生成候选；SchemaValidator 检查格式；SemanticValidator 检查能力、参数、依赖和条件；PlanEvaluator 比较候选收益与代价。

ModelRequest 保存 purpose、context_version、generation、capability_version、deadline 和 max_cost。Plan 包含 goal_id、steps、dependencies、success_predicate、assumptions、evidence_ids、estimated_cost 和 revision。每个步骤引用能力或技能 ID，不返回任意 Shell、Python 或未注册工具代码。

## 规划过程

确定目标和可观察成功条件 → 检索可用技能 → 装配上下文 → 生成有限候选 → 校验结构 → 校验语义 → 检查步骤图无环及预算 → 静态模拟前置后置条件 → 提交可执行计划。首版计划最多 8 步、候选最多 3 个，均为实验起始上限。

格式错误至多一次修复，修复仍占同一调用预算。结构有效但无证据支撑的计划返回 NEEDS_CLARIFICATION；未知能力返回 UNSUPPORTED_CAPABILITY；取消或上下文代次失效则仅记录候选，不交给调度器。

重规划由实际结果与预期不符、关键前置条件失效或目标修订触发；保留已确认完成的步骤及效果，不重复规划其外部执行。每个目标限定重规划次数，耗尽后进入 blocked 或 failed。

## 难点与实验

R13：长程任务分解、前置条件遗漏和错误反馈后的修复。使用公开可描述的仿真领域或自建小型动作世界，固定状态转换和目标判定器；比较规则模板、单次模型规划和带反馈重规划。

指标包含 schema 合法率、语义合法率、仿真成功率、重复动作率、证据引用正确率、调用成本及 p95 延迟。模型版本、提示版本与评估数据版本一起记录，供应商变更必须重跑基准。

## 异常与验收

重试只适用于模型生成请求，不延伸到外部动作；采用有界退避及熔断，避免多个重试层相乘。流式返回的半个计划不执行。模型返回“已成功”不构成执行证据。

验收注入坏 JSON、缺字段、越界参数、环依赖、未知能力、来源伪造、超时及过时返回；所有非法候选不得进入动作通道。无法达到复杂规划目标时明确缩小支持的任务集合。

## 开发拆分

- M13-A：计划 DSL、模型适配契约、仿真领域及基线评估。
- M13-B：网关、格式与语义校验、预算、取消和重规划。
- M13-C：长程任务与异常矩阵评估、成本控制及模型版本回归。
