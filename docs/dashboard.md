# 本地管理台 · 0.6.0

管理台将认知状态、逐轮语音、来源证据和运行控制放在同一个本地页面中。前端是随 Python 包分发的 HTML/CSS/JavaScript，后台使用标准库 HTTP 服务，不需要另装 Node、启动前端开发服务器或连接外部 CDN。

## 一条命令启动

在仓库目录执行：

```sh
python3 -m consciousness
# 等价于：
python3 -m consciousness serve --data-dir local-data/voice --port 8765
```

访问 `http://127.0.0.1:8765/`。命令同时提供前端页面和后台 API；语音配置通过本地检查时自动启动麦克风会话。尚未配置云模型或 TTS 时，页面仍可启动、浏览已有数据，并显示缺少配置，麦克风不会打开。Ctrl+C 或 SIGTERM 停止管理台时，会停止其管理的语音进程及录放音子进程。

```sh
# 只看数据，暂不自动录音；之后可从页面点击开始收听。
python3 -m consciousness serve --no-voice
# 查看其他已有数据目录，使用其他端口。
python3 -m consciousness serve --no-voice --data-dir local-data/ci --port 8766
```

数据目录决定看到哪套状态。默认与此前 `voice` 命令一致；已有 `run` / `simulate` 数据需要指定对应目录。原 `voice` 命令保留为不带 Web 的独立命令，也是管理台启动子进程使用的入口。管理台仅控制自己启动的语音进程；不接管外部已经运行的实例。相同数据目录的写入实例由 Journal 文件锁互斥。

## 可见内容

| 页面 | 数据与含义 |
| --- | --- |
| 总览 | 事实主张、经验、目标、累计云调用、失败及 TTS 次数，最近对话和运行阶段 |
| 听见与回应 | 本轮语音观察、回复文本、时间、合成/播放/失败/取消状态；不是录音播放器，也不承诺逐字转录准确 |
| 记忆与证据 | 主张、来源证据和冲突，查看有效性、撤回状态和完整记录，点击证据 ID 精确定位 |
| 学习与经验 | 经验及成功结果、候选、独立评估和发布状态；“候选已生成”不等于“技能已学会” |
| 动机与目标 | 当前充电动机、新增的触发/解决历史、关联目标，以及目标完成条件和状态 |
| 场景/自身状态/情绪/身份 | 地点、实体、遥测、情绪刺激事件、角色偏好等已存储状态；不是对真实内在体验的证明 |
| 技能/反射/联想/日历/知觉 | 各模块结构化状态；未运行模块显示真实空状态 |
| 云调用 | 任务、模型、候选结果、使用量、状态与提示词指纹；不含 API Key |
| 事件追踪 | 最近事件、修订、原因 ID 与载荷，按游标加载更早事件 |
| 连接与配置 | 音频工具、模型及 TTS 是否配置，当前管理进程的运行消息；不验证供应商余额或网络连通性 |

分类列表每页 30 条，支持当前分类内容搜索、完整记录展开。页面每 2 秒刷新运行概要；模块修订变化时更新列表，正在输入或展开详情时保留操作现场，可手动刷新。事件列表通过按钮翻页；语音页面展示最近 100 轮。

## 数据与进程设计

- **单写入者**：语音子进程继续使用 Journal/StateStore 写事务；管理台使用 SQLite `mode=ro`、`query_only` 读取 WAL，概要在同一读事务内装配，不抢占运行时写锁。
- **逐轮对话投影**：语音识别候选通过既有校验后记录 `heard`，表达候选通过校验后记录 `reply`。合成前、播放前、播放后更新阶段，失败和取消也留痕。此摘要最多保留 200 轮，原始候选仍遵循云调用账本规则。
- **动机历史**：低电量触发时记录原因、样本和目标；恢复时记录解决时间与证据。保留最近 200 个动机。旧版本已删除的历史无法凭空恢复。
- **进程控制**：开始按钮进行配置预检并启动一个语音子进程，重复启动返回冲突；停止先发中断信号，5 秒未退出则终止该进程组。每次会话最多 100 轮、无有效语音 300 秒退出，仍受持久预算约束。
- **故障可见**：子进程退出码与近期消息显示在配置页；页面断线后禁用控制按钮并自动重连。pending 状态表示未确认，不自动解释为成功，不自动重播上次音频。

管理台是可观察与控制入口，不自动采纳云候选、不自动把每次对话写成事实、不绕过学习验证去发布技能。完整自主学习、通用动机生成等仍按研发计划推进。

## 本地访问边界

服务固定绑定 `127.0.0.1`，校验 Host、Origin 与浏览器来源；控制请求还要求页面会话随机令牌。无任意文件读取、任意 SQL 或终端执行接口。内容以文本节点渲染，页面禁止内联脚本和第三方资源。环境凭据不通过接口返回、不写入浏览器。

这不是多用户远程后台：同一台机器上的其他程序可能访问数据，不提供账号和权限系统。不要直接做公网端口转发。需要远程管理时，应另外实现认证、访问控制与审计。

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/overview` | 模块修订与分类计数、对话摘要、运行状态与配置就绪标记 |
| GET | `/api/records?module=knowledge&collection=claims&page=0&q=` | 分页读取；可加 `id` 精确定位；module 使用固定白名单 |
| GET | `/api/events?before=0` | 最新 50 条；before 使用上一页最后一条 seq |
| POST | `/api/voice/start` | 开始会话；同源 + `X-CSRF-Token`，正文 `{}` |
| POST | `/api/voice/stop` | 停止本管理台的会话；同上 |

前端资源随 wheel 分发，CI 检查安装包资源。验证记录见 [管理台验收报告](validation/dashboard-report.md)。云服务配置见 [云模型](cloud-models.md) 和 [语音对话](voice.md)。
