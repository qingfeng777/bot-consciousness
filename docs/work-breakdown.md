# 模块研发工作包

本表是详细研发范围的唯一估算台账。每个模块拆成 A 契约与基线、B 工程实现、C 模块验证三包；具体产物与测试条件见链接中的模块设计。实际状态单独维护在 [研发进度](progress.md)，前期设计文档不计作实现完成。

依赖表示工作包完成后才能关闭当前工作包；开发期间可用冻结契约和替身并行。每个 B 包还依赖自己的 A 包，每个 C 包依赖自己的 B 包。M01-A 为根，其他 A 包依赖 M01-A，M20-A 也遵守此规则。接口设计互相参考不构成工程任务互相等待。

每包人日已含本模块正常单测、代码评审与文档；C 包包含专门算法或故障实验。跨模块场景验收由集成台账单独计量，避免重复统计。B 包超过 10 人日时按模块中的组件拆成 2 至 5 人日实施项，父包完成要求所有子产物验收，不把未估算子项再额外加总。
