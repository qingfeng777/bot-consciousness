## 本地验证证据

环境为 Linux、Python 3.10.12。使用 `python3 -m unittest discover -s tests -v`：**51 项测试通过**，一次完整运行约 15.0 秒。耗时受机器负载影响，不作为系统性能承诺。

| 验证 | 实际覆盖 | 限制 |
| --- | --- | --- |
| 1,000 条生成状态轨迹 | 每条 10 次操作，共 10,000 次；检查单槽位、队列上限、幂等与终态稳定 | 状态存储层轨迹，不等于 1,000 次完整机器人场景 |
| 1,000 条输入执行 | 固定种子，全部完成，模拟外部并发最大值为 1 | 同批受理，无真实设备和模型负载 |
| 中断与停止 | 延迟停止确认、重复中断、无效回执、超时冻结和显式核对 | 依赖可控模拟器，未证明真实设备停止时限 |
| 真子进程崩溃 | 动作效果已持久化、任务结果未写回时 os._exit；重启无重复效果 | 覆盖一个实际进程终止窗口，其他窗口以注入与重建测试覆盖 |
| 存储异常 | 事务回滚、紧急淘汰回滚、执行中写失败后的停止请求 | 未进行物理磁盘断电测试 |
| CLI 与回放 | 持久运行、inspect、resume、非法输入、批量及带时间抢占回放哈希稳定 | 时间回放仅限内置模拟器、有界回调链 |

`examples/basic.jsonl` 的规范化结果哈希为 `2f923a2205b323137783dada11e2e292b5f10f686944221672a8d57211856491`，含 4 条输入，其中 1 条重复，最终 3 个动作完成。哈希只覆盖去除随机 ID 和墙钟后的结果序列。

CI 配置覆盖 Python 3.10 和 3.12；远端运行结果以对应 GitHub Actions 为准，不能用本地 3.10 成功代替 3.12 已通过。本地完成 100 次抢占、200 条输入、20 条/秒的真实时钟微基准：受理后至 stop 请求 p95 为 2.005ms，包含受理存储耗时的入口至 stop p95 为 5.642ms，最大外部并发为 1。该负载下满足请求延迟 ≤100ms，不能外推真实设备停止时间。详细环境、源码哈希及范围见 [G1 验证报告](validation/g1-report.md)。未执行 72 小时长跑，也未完成 G1 全部退出门槛或完整系统全范围验收。
